# iOS Welcome Practice App

A tiny SwiftUI app that displays a welcome message.

## How to run in Xcode

1. Open Xcode and create a new **iOS App** project.
2. Choose **SwiftUI** as the interface.
3. Replace the generated `ContentView.swift` and app entry file with:
   - `ContentView.swift`
   - `WelcomeApp.swift`
4. Select an iPhone simulator and press **Run**.

## What this demonstrates

- App entry point using `@main`
- A basic `VStack` layout
- Text and SF Symbol usage in SwiftUI
